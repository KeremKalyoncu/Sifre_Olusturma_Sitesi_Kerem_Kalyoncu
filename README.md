## 📋 Hakkında

Kullanıcının belirlediği uzunlukta güçlü, rastgele şifreler üreten basit ve kullanışlı
bir web aracı. Üretilen şifre tek tıkla panoya kopyalanabilir; ayrıca şifrenin gücünü
kontrol etmek için harici bir güç testi sitesine yönlendirme sunar.

## ✨ Özellikler

- 🎲 İstenen uzunlukta rastgele şifre üretimi
- 📋 Tek tıkla panoya kopyalama + bilgilendirme mesajı
- 💪 Şifre gücü kontrolü için site yönlendirmesi
- 🎨 Özel arka plan ve arayüz tasarımı

## 🚀 Çalıştırma

```bash
git clone https://github.com/KeremKalyoncu/Sifre_Olusturma_Sitesi_Kerem_Kalyoncu.git
```

`index.html` dosyasını tarayıcıda açmanız yeterlidir.
